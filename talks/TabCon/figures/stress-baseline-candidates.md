# Further baselines for the opening stress comparison

Status, 2026-10-27: GRF, Local Linear Forest, BDE, RF-IJ and DRF have each completed all 1,280 original paired tasks, with zero failures, and are in the eleven-method scatter. The user excluded Bayesian credible-interval baselines: BART and GP are cancelled and not plotted. DeepLR remains cancelled. The archived radar retains the original six methods.

The intended target for additional confidence-interval comparisons is the regression mean E[Y|observed X]. Code inspection of the existing stress generator found that the saved oracle is a transformed latent target T(Z), which is not guaranteed to equal that conditional mean. The current local figure faithfully displays those stored results and labels their target as the saved latent oracle. At the user's explicit request, these additional experiments preserve the original task realizations and saved oracle, rather than changing the generator or estimand. The target caveat therefore applies to all eleven methods in this comparison. A predictive interval for a future outcome answers a different question; the existing native TabPFN PI curve is explicitly labeled as that reference.

| Priority | Candidate | Interval and reason to include | Primary source |
|---|---|---|---|
| 1 | Honest regression forest (GRF) | A strong tree-based conditional-mean baseline. Obtain estimated sampling variance from the honest regression forest and construct nominal confidence intervals. | [Official regression-forest prediction documentation](https://grf-labs.github.io/grf/reference/predict.regression_forest.html) |
| 2 | Local linear forest | Tests whether local linear correction improves mean estimation and confidence intervals relative to an ordinary honest forest. This is related to GRF rather than an independent model family. | [Official local-linear forest prediction documentation](https://grf-labs.github.io/grf/reference/predict.ll_regression_forest.html) |
| 3 | Distributional random forest with inference | Adds a distribution-adaptive forest and its bootstrap-based inference procedure. Use the inference method for the conditional mean, not raw quantiles of Y. | [Näf et al., JMLR 2023](https://www.jmlr.org/papers/v24/23-0185.html) |

## Additional candidates

All candidates below work from one observed training dataset. Splitting, resampling, or generating parametric bootstrap responses reuses that dataset or a fitted model; it does not require collecting independent training datasets. Their validity conditions differ, so the table distinguishes frequentist inference from posterior intervals and exploratory adaptations.

| Candidate | Target and construction | Fit to this comparison / limitation | Primary reference and implementation |
|---|---|---|---|
| **Bootstrapped Deep Ensembles (BDE)** | Approximate CI for the regression function. Adds a parametric-bootstrap stage to deep ensembles to estimate variation from random training responses as well as optimization. | Strong new neural baseline. The paper adopts fixed covariates and Gaussian, potentially heteroscedastic noise; heavy-tail and contamination cases test misspecification. Use its CI, excluding future-observation noise. | Sluijterman, Cator & Heskes, *Neurocomputing* 656, 131500 (2025): [published paper](https://doi.org/10.1016/j.neucom.2025.131500), [author preprint](https://arxiv.org/abs/2202.10903), [author code](https://github.com/LaurensSluyterman/Bootstrapped_Deep_Ensembles). |
| **DeepLR** | Likelihood-ratio CI for a neural-network output, including a regression mean. Perturbs the fit and inverts a likelihood-ratio test; intervals can be asymmetric. | Particularly relevant to amortization. The published implementation trains two additional networks per query interval. Use a predeclared smaller paired benchmark with all comparators if full evaluation is too expensive. Requires likelihood/regularity assumptions and numerical approximations. | Sluijterman, Cator & Heskes, *Machine Learning* 114, 116 (2025): [paper](https://link.springer.com/article/10.1007/s10994-024-06639-3), [author code](https://github.com/LaurensSluyterman/Likelihood_ratio_intervals), including a regression implementation and an XGBoost example. |
| **Random Forest + infinitesimal jackknife (RF-IJ)** | Estimates sampling variance of a fitted bagged/random-forest predictor, which can be used for a Wald interval. | Implemented with the official R ranger 0.18.0 package; different implementation from honest GRF, but a related family. Variance estimation alone does not correct forest bias, so nominal coverage of the true f(x) is not automatic. | Wager, Hastie & Efron, *JMLR* 15, 1625–1651 (2014): [paper](https://www.jmlr.org/papers/volume15/wager14a/wager14a.pdf); [official ranger prediction API](https://imbs-hl.github.io/ranger/reference/predict.ranger.html). |
| **HulC / Adaptive HulC around a base estimator** | Forms a confidence interval from the hull of estimates fitted on disjoint data subsets; the adaptive variant estimates median bias using subsampling. | An exploratory alternative to bootstrap, potentially wrapping a mean estimator. Application to TabPFN/XGBoost at a query is a proposed adaptation, not a verified result from the paper. Requires median-bias control; do not assume zero median bias for a regularized learner. Splitting also reduces each fit's context size. | Kuchibhotla, Balakrishnan & Wasserman, *JRSS B* 86, 586–622 (2024): [paper](https://academic.oup.com/jrsssb/article/86/3/586/7499155), [author implementation](https://github.com/Arun-Kuchibhotla/HulC). |
| **Local-polynomial robust bias-corrected CI** | Corrects smoothing bias and accounts for bias-estimation variability when forming a regression-mean CI. | Useful low-dimensional diagnostic, not a drop-in baseline for the whole high-dimensional mixed-feature benchmark. The standard `nprobust` regression interface uses a scalar covariate; do not give it the hidden base_target or reduce X with oracle knowledge. | Calonico, Cattaneo & Farrell, *JSS* 91(8) (2019): [paper](https://www.jstatsoft.org/article/view/v091i08), [official package](https://github.com/nppackages/nprobust). |

Completed additions: **GRF, Local Linear Forest, BDE, RF-IJ and DRF** (eleven plotted methods). **DRF** uses the official drf 1.3.1 native uncertainty API for the mean functional. **BART and GP are cancelled** because the user excluded Bayesian credible intervals; do not restart them. DeepLR remains cancelled for cost. The older Bayesian pilot records are diagnostic history only.

A recent research lead is Meng & Li, *Inference for Deep Neural Network Estimators in Generalized Nonparametric Models* ([arXiv:2504.09347](https://arxiv.org/abs/2504.09347), v4, March 2026; [2026 JASA publication](https://doi.org/10.1080/01621459.2026.2637894)). Its ensemble-subsampling procedure targets conditional means, but the showcased logistic/Poisson/binomial settings and applicability to this continuous-response stress protocol need further checking. It is not yet on the implementation shortlist.

Ordinary quantile regression, native predictive quantiles, and standard conformal prediction intervals should not be silently counted as extra mean-CI methods. They concern future outcomes unless accompanied by a separate, justified mean-inference procedure. Likewise, random-seed disagreement in a deep ensemble is not by itself a calibrated sampling CI.

## Conditions for a comparable rerun

- Pair all methods on identical task realizations, context/query rows, nominal levels and validated oracle targets. If correcting the latent-oracle issue requires changed generators or targets, rerun every compared method under that common protocol; do not combine those new results with the original ten-setting, 128-task-per-setting table.
- Fit preprocessing to context data only. Fix the missing-value and categorical-data treatment, and record any unsupported setting rather than dropping it from an average.
- Tune without access to query outcomes or the true f(x). Report fit plus inference time on the same hardware and query/context sizes.
- Keep confidence/credible intervals for f(x) separate from prediction intervals for Y. Report per-setting coverage and length together; do not rank interval width without considering coverage.
- Retain per-task results and method-specific seeds. Once the data are available, regenerate the scatter, archived radars, and opening statistics from the same CSV; add a second comparison panel if the legend becomes crowded.
